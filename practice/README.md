# Practice

Diretório focado em uma prática mais completa que os exercícios, enquanto um exercício normalmente trabalha conceitos isolados de alguma aula ou anotação, a prática tem como objetivo buscar diferentes conhecimentos em programas e situações do ecossistema **Java** proximas do desenvolvimento real de um software.

---

## Estrutura do repositório
```text
java-lab/
    └── practice/
            ├── variavéis/
            │       └── VariablePractice.java
            │       └── TypeConversionPractice.java
            ├── condicionais/
            │       └── IfElsePractice.java
            │       └── SwitchPractice.java
            ├── loops/
            │       └── ForLoopPractice.java
            │       └── WhileLoopPractice.java
            └── etc...
```
Essa estrutura é apenas um exemplo do modelo do diretório, os nomes dos documentos **md** podem ser renomeados, para que facilitem a sistematização das anotações e modulação dos conteúdos.
