# Exercices

Diretório focado nos exercícios desenvolvidos e propostos dentro dos estudos e anotações do **Java-lab**.

O objetivo dessa seção é reforçar os conceitos anotados e estudados, aplicando isso em exercícios resolvendo problemáticas expecíficos para cada tópico anotado e estudado.

---

## Estrutura do diretório
```text
java-lab/
    └── exercices/
            ├── tipos de dados/
            │       └── dados.java
            │       └── README.md
            ├── estrutura de repetição/
            │       └── repetição.java
            │       └── README.md
            ├── estrutura de decisão/
            │       └── decisão.java
            │       └── README.md
            └── etc...
```
Essa estrutura é apenas um exemplo do modelo do diretório, os nomes dos documentos **md** podem ser renomeados, para que facilitem a sistematização das anotações e modulação dos conteúdos.

Os README.md dentro das pastas de cada exercício será utilizado como anotação do exercício, análise do problema, modo de resolução, sendo totalmente complementar a anotação dentro de [notes](../notes) que levou a tal exercício.
