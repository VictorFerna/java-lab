# ☕ Java Lab

Repositório dedicado ao estudo, prática e aprofundamento em **Java**.

O **Java Lab** funciona como um ambiente contínuo de aprendizado, reunindo anotações, exercícios, desafios, experimentos e implementações desenvolvidas durante meus estudos da linguagem e de seu ecossistema.

A proposta não é apenas armazenar códigos prontos, mas registrar o processo de aprendizado: entender conceitos, testar comportamentos da linguagem, resolver problemas e transformar teoria em prática.

## Objetivo

Este repositório foi criado com o objetivo de construir uma base sólida em Java por meio de estudo progressivo e aplicação prática.

Ao longo do desenvolvimento do repositório serão abordados desde os fundamentos da linguagem até conceitos mais avançados utilizados no desenvolvimento profissional de software.

O conteúdo será produzido principalmente a partir de:

- estudos de cursos e documentações;
- anotações próprias;
- exercícios de fixação;
- desafios de programação;
- experimentos com a linguagem;
- pequenos projetos e aplicações práticas;
- estudos sobre a JVM e o ecossistema Java.

Além de servir como registro pessoal de aprendizado, o repositório também poderá ser utilizado por outras pessoas interessadas em estudar ou revisar Java.

## Estrutura do repositório

```text
java-lab/
│
├── challenges/
├── exercises/
├── experiments/
├── notes/
├── practice/
└── README.md
```
A organização interna de cada diretório é documentada em seu respectivo **README.md**.

### [`notes/`](/notes/)

Anotações organizadas sobre os conteúdos estudados.

Aqui ficam explicações, conceitos importantes, exemplos e observações sobre Java, JVM, orientação a objetos e outros assuntos relacionados ao ecossistema da linguagem.

### [`exercises/`](/exercices/)

Exercícios desenvolvidos durante os estudos.

O objetivo desta seção é reforçar os conceitos apresentados nas anotações por meio da resolução de problemas específicos.

### [`practice/`](/practice/)

Implementações práticas um pouco mais completas.

Enquanto os exercícios normalmente trabalham conceitos isolados, esta seção busca combinar diferentes conhecimentos em programas e situações mais próximas do desenvolvimento real.

### [`challenges/`](/challenges/)

Desafios utilizados para testar conhecimento e raciocínio.

Eles podem envolver algoritmos, orientação a objetos, estruturas de dados, APIs da linguagem, refatoração e resolução de problemas mais complexos.

### [`experiments/`](/experiments/)

Área destinada à experimentação.

Aqui podem existir pequenos códigos criados especificamente para investigar como determinada funcionalidade do Java ou da JVM se comporta.

Exemplos:

- comportamento de tipos;
- referências e objetos;
- Garbage Collector;
- Collections;
- Streams;
- Threads;
- concorrência;
- recursos de versões modernas do Java.

Nem todo código desta pasta representa uma aplicação completa. O objetivo é experimentar, observar e compreender.

## Organização dos estudos

O conteúdo será desenvolvido de forma progressiva.

A ideia é partir dos fundamentos e avançar gradualmente para conceitos de engenharia de software e desenvolvimento profissional com Java.

Entre os principais assuntos que poderão aparecer no repositório estão:

**Fundamentos**

- funcionamento básico do Java;
- JDK, JVM e bytecode;
- compilação e execução;
- variáveis e tipos;
- operadores;
- estruturas condicionais;
- estruturas de repetição;
- métodos.

**Orientação a Objetos**

- classes e objetos;
- encapsulamento;
- construtores;
- herança;
- polimorfismo;
- abstração;
- interfaces;
- composição.

**Java intermediário**

- tratamento de exceções;
- generics;
- Collections Framework;
- enums;
- records;
- manipulação de arquivos;
- datas e horários;
- lambdas;
- Stream API.

**Java avançado**

- memória e Garbage Collector;
- concorrência;
- threads;
- virtual threads;
- programação assíncrona;
- JVM;
- reflexão;
- boas práticas;
- arquitetura e organização de aplicações.

**Ecossistema**

Com o avanço dos estudos, o repositório também poderá incluir tecnologias e ferramentas utilizadas em conjunto com Java, como:

- Maven;
- Gradle;
- JUnit;
- Spring;
- Spring Boot;
- bancos de dados;
- APIs REST;
- persistência de dados;
- testes automatizados.

## Filosofia do Java Lab

A proposta deste repositório pode ser resumida em:

**Estudar → entender → implementar → experimentar → revisar.**

Sempre que possível, os conceitos estudados serão acompanhados de código e aplicação prática.

O objetivo não é apenas saber escrever a sintaxe de Java, mas compreender **por que o código funciona, como a linguagem funciona e como utilizar seus recursos para construir software de qualidade**.

## Fontes de estudo

Os conteúdos deste repositório podem utilizar como referência cursos, livros, documentações oficiais e outros materiais educacionais.

As referências utilizadas ao longo dos estudos serão registradas junto das respectivas anotações quando necessário.

Uma das fontes utilizadas inicialmente é o curso de introdução a Java da **DataCamp**.

Também será utilizada como referência principal a documentação oficial do Java e materiais relacionados ao ecossistema da linguagem.
