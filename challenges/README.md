# Challenges

Diretório focado em problemáticas que desafiam a capacidade lógica, algoritmica, conhecimento da linguagem e de aplicações reais. 

Os desafios podem envolver API's, orientação a objetos, estruturas de dados, Algoritmos, refatoração e resolução de problemas mais complexos.

---

## Estrutura do repositório
```text
java-lab/
    └── challenges/
            ├── conta no banco/
            │       └── BankAccount.java
            │       └── BankAccountChallenge.java
            │       └── README.md
            ├── validador de senha/
            │       └── PasswordValidator.java
            │       └── README.md
            ├── carrinho de compra/
            │       └── Product.java
            │       └── ShoppingCart.java
            │       └── ShoppingCartChallenge.java            
            │       └── README.md
            └── etc...
```
Essa estrutura é apenas um exemplo do modelo do diretório, os nomes dos documentos **md** podem ser renomeados, para que facilitem a sistematização das anotações e modulação dos conteúdos.

Os README.md dentro de cada desafio serve para explicar o problema antes de mostrar a solução.
